Expects each file to have been through filesdb.with_links. One thing on a row changes anything: Public (ADR-0042). A row used to carry six forms, and on a phone two files filled the screen with boxes while the filename, the thing somebody came for, was the smallest part of it. Everything else done to a file is done on its own page, and the row is the way there: its name is the link, stretched over the row, so the whole of it can be tapped.
