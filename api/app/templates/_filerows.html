{# A list of files, one row a file: what it is, what it is called, what it is linked to, how big and how old, and a button that downloads it. Expects each file to have been through filesdb.with_links. Nothing on a row changes anything. That is the whole design of the list: a row used to carry six forms, and on a phone two files filled the screen with boxes while the filename, the thing somebody came for, was the smallest part of it. Everything done to a file is done on its own page, and the row is the way there: its name is the link, stretched over the row, so the whole of it can be tapped. The chips and the download sit above that stretch, and are links of their own. `chips` is whether to say what each file is linked to -- yes on /files, no in an item's own panel, where the answer is the page it is on. #} {% import "_fileicons.html" as FI %} {% import "_ui.html" as U with context %} {% macro rows(files, authed, chips=true) %}

    {{ f.note | linked }}
    {% endif %} {% if chips %} {% if f.chips %}
    {% for c in f.chips %}{{ c.label }} {{ c.name }}{% endfor %}
    {% elif authed %}
    {{ U.chip('Unlinked', 'quiet') }}
    {% endif %} {% endif %}
    {{ f.what.size }}{% if f.created_at %} · {{ log_stamp(f.created_at, authed) }}{% endif %} {# A PDF or a text file is read where it is tapped (ADR-0030, ADR-0035); anything else is saved.
