The specs used to be a fourth column, and a card's are longer than everything else in the row put together -- "Chip: Trident TVGA9000B | Interface: ISA 16-bit | Memory: 512KB | Connector: DE-15" beside an asset id and a name. The column took most of the table's width, squeezed the name and the id it was sitting next to into a few characters each, and still wrapped to three or four lines, so every row stood that tall whether it had specs in it or not. So the row says which part this is, and the line below it says what the part is: the same pairs, laid out as labelled columns that the eye runs along rather than a run of "Key: value |" to be read as a sentence. A part with nothing recorded gets no second line at all, which is also how the list shows at a glance which parts have been written up and which are still just a name. Each part is one tbody, so its two rows cannot be split and the rule is drawn between one part and the next rather than between a part and its own specs.
